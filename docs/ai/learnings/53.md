---
title: 'EXIT trap on a local var inside $(...) never fires cleanly'
issue: 53
---

**Learning:** A `trap ... EXIT` set in a function called via `$(...)` fires when the subshell exits, after the function's `local` vars are gone, so under `set -u` it errors and cleans nothing; and macOS `mktemp` ignores `TMPDIR`, so a leak test needs a `mktemp` stub on PATH.
